HuiGod刷课 · v0.2.0 · 离线使用教程

安装、设置，然后开始。

浏览器中显示为“学习通自用助手”。题库管理与 AI 设置各有独立入口，默认每次最多调用 AI 1000 次。

01 · 加载正确的文件夹

  1. 先把 HuiGod刷课.zip 完整解压到固定位置。
  2. Edge 打开 edge://extensions；Chrome 打开 chrome://extensions，开启“开发人员模式”。
  3. 点击“加载解压缩的扩展”，进入并选择 extension 文件夹。
  4. 确认扩展版本为 0.2.0，刷新设置页和课程页。
HuiGod刷课/
├─ extension/  ← 浏览器选这一层
│  ├─ manifest.json
│  └─ ...
├─ 使用教程.html  ← 本教程
└─ 使用说明.md
提示“清单文件丢失”通常是选到了外层文件夹。应选择直接包含 manifest.json 的 extension 目录。

原目录覆盖更新后，点扩展卡片的“重新加载”可保留原设置。若换了新目录，先停用旧副本，再加载新版并检查 AI 配置；不要同时启用两个版本。

02 · 选择你的答案来源

题库管理

点击“题库管理” → 选择自己的 JSON 文件或编辑内容 → 点击“保存题库”。导入会替换本地题库；随包示例只有格式演示题，不是课程题库。

[{"question":"1+1等于几？","options":["1","2"],"answer":["2"]}]

answer 建议写完整选项文字，多选每个答案单独一个字符串。使用字母答案时须同时保留原始 options，避免乱序选错。

AI 设置

没有匹配题库时，可使用自己的 AI 接口。勾选“启用 AI 答题”；处理加密文字或图片题时，再开启“图片与加密文字识别”。

项目填写方法
API 基础地址兼容 chat/completions 的地址，如此前测试过的 https://你的API服务地址/v1
模型名称服务商提供的模型 ID，如 你的模型ID；识图需要支持图片输入
API Key自行填写有效密钥，不要勾选“仅删除已保存的密钥”
调用次数新安装默认 1000，最高可设 10000；已有个人设置会保留，可手动调整
第三方 AI 可能收费。达到每次上限会暂停，重新启动会重新计数。题库保存与 AI 保存互不覆盖。

保存之后返回课程页重新启动。开启自动提交、自动切章后，仍建议先旁观一个章节，核对真实记录。

03 · 在课程页启动

  1. 登录学习通并进入具体章节的视频/测验页。
  2. 点击工具栏扩展图标，再点 启动当前课程。
  3. 视频自然播放；选择题填写完成后，开启自动提交时会处理可识别的确认弹窗。
  4. 确认成功结果后，助手才会尝试下一个任务或章节。
  5. 需要停止时，点主弹窗或课程浮窗的“停止”。运行记录可在主弹窗展开查看。

遇到问题时

现象处理
临时播放失败助手最多尝试 3 次。浏览器要求一次手动播放时，点播放器即可继续，不必重新启动；如果已暂停，处理网络后再启动。
出现确认提交弹窗新版会处理可识别的本页或同源父层弹窗。若仍提示未找到确认按钮，请先手动确认并核对平台记录，不要重复交卷。
题库未命中 / 没有可用答案导入匹配题库或配置有效 AI。程序不会在失败时猜选项。
提交后不切章先核对平台是否已提交成功、是否还有其他任务。未识别到成功状态或入口会暂停，不能只根据按钮点击判断完成。
验证码、人脸核验、正式考试自行处理。插件不自动完成验证或正式考试。
更新后还是旧界面扩展页重新加载，确认 0.2.0，再刷新设置和课程页；检查是否同时装了旧副本。
